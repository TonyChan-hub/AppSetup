AppSetup少写样板，直接开工

一条命令生成无业务逻辑的 React Native / Flutter 脚手架，并在 macOS 上配置 Android / iOS 工具链。

快速开始
下载 Zippy
GitHub

React Native 脚手架

npx @bear1210/create-rn-template — RN 0.81、TypeScript、日志、i18n、SQLite、MMKV、husky 与 Cursor 规则。

Flutter 脚手架

分层 lib/ 结构，内置 Dio、GoRouter、Provider、sqflite 日志、ScreenUtil、ARB 国际化，不含业务域。

环境助手

macOS 上 setup-rn-android-env / setup-rn-ios-env（支持国内镜像），以及 check-mobile-env 环境检查。

Zippy 调试器

Tauri 桌面工具 — Git（多仓库 + SSH）、Inspector（MMKV / SQLite / 网络 / 性能）、Tools（adb / 模拟器快捷操作）。可在 Zippy 文档页下载 macOS 安装包。
